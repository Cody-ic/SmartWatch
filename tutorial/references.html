版本与边界

  • STM32U575：以仓库 HAL1 代码和对应参考手册为准；F1/F4 等教程用于比较原理，不照搬寄存器与引脚。
  • LVGL 使用 8.3 风格接口；Dart/Flutter 与 BLE 插件以 pubspec.lock 为准，不能直接按最新主版本替换。
  • ST.AI 的界面、CLI 与生成 API 会随版本变化；以当前安装帮助、模型报告和生成头文件确认。教程不运行模型导出或外设工程生成。
  • 在线资料核对日期：2026-10-23。ST Wiki 部分页面当时处于维护状态，未作为唯一依据；优先保留官方 HAL 源码、规范和可读文档链接。
  • 原型网络论文用于理论出处；项目实际采用的归一化/余弦原型与门控流程另作说明。
