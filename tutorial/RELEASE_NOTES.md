# 图解教程 v0.2.0 预览版

## 内容

全站 **79 篇课程、88 个 HTML 页面**。保留裸机与 FreeRTOS 两章 29 篇主线；五条支线共 50 篇，各支线首页提供学习路线，目录点击可展开分篇内容。

| 支线 | 内容 | 课程数 |
| --- | --- | --- |
| 一 | 显示驱动与 LVGL | 7 |
| 二 | CH582M 开发与蓝牙桥接 | 8 |

| 四 | 数据、训练与 STM32 模型部署 | 12 |

- CH582M 支线比较实际两套工程的工具、外设接口与运行方式，沿 UART1、事件处理、GATT 服务、FFE2 写入与 FFE3 通知讲清双向桥接。
- App、AI 分别补齐 Dart 与 Python 语法，再逐步接入页面、异步、蓝牙、数据集、训练、评估和部署。
- 个性化支线从二维类别中心走到项目会话与备份；升级支线从启动、镜像走到普通文件的暂存、试运行和回退模型。
- 配套提供 Dart、Flutter、Python 示例、原创图解与原型交互。电量示例与实际 App 的负和校验交叉核对。

完整解压 `SmartWatch-Tutorial-v0.2.0.zip`，打开 `tutorial/index.html`。也可在解压目录运行 `python -m http.server 8000`，访问 `http://localhost:8000/tutorial/`。

正文、样式、图解和网页交互可离线阅读。外部源码、数据手册与工具链接需联网；运行 Flutter/Python 实验需另行准备对应工具和依赖，详见包内示例 README。学习进度保存在当前浏览器，路线首页不计入课程完成数。

# 图解教程 v0.1.0 预览版

发布日期：2026-10-25。Git 标签：`tutorial-v0.1.0`。

## 内容

全站包含 40 篇课程、44 个 HTML 页面，所有样式、脚本、截图和图解均随包提供。

- **第一章：裸机开发。** GPIO、UART、中断、SPI、IIC、ADC、无线通信、DMA，嵌入式拓展及裸机逻辑综合。IIC 下设四篇器件与采样实战，ADC 下设项目麦克风，无线通信下设手写协议与项目实现。
- **第二章：FreeRTOS。** 一篇函数指针、线程与并发前置，以及八篇任务创建、调度、信号量、队列、共享资源、声音数据交接、内存与项目整合。
- **四条支线。** 显示驱动与 LVGL 七篇，手机应用、AI、原型学习及无线升级四篇实践。

## 阅读方式

完整解压 ZIP 后打开 `tutorial/index.html`。也可在解压目录运行 `python -m http.server 8000`，访问 `http://localhost:8000/tutorial/`。

正文和网页交互可离线使用，引用的 GitHub 源码、厂商数据手册及外部工具需联网。学习进度仅保存在当前浏览器；阻止本地存储不会妨碍正文阅读。
