# 图解教程 v0.1.0 预览版

发布日期：2026-10-25。Git 标签：`tutorial-v0.1.0`。

## 内容

全站包含 40 篇课程、44 个 HTML 页面，所有样式、脚本、截图和图解均随包提供。

- **第一章：裸机开发。** GPIO、UART、中断、SPI、IIC、ADC、无线通信、DMA，嵌入式拓展及裸机逻辑综合。IIC 下设四篇器件与采样实战，ADC 下设项目麦克风，无线通信下设手写协议与项目实现。
- **第二章：FreeRTOS。** 一篇函数指针、线程与并发前置，以及八篇任务创建、调度、信号量、队列、共享资源、声音数据交接、内存与项目整合。
- **四条支线。** 显示驱动与 LVGL 七篇，手机应用、AI、原型学习及无线升级四篇实践。

## 阅读方式

完整解压 ZIP 后打开 `tutorial/index.html`。也可在解压目录运行 `python -m http.server 8000`，访问 `http://localhost:8000/tutorial/`。

正文和网页交互可离线使用，引用的 GitHub 源码、厂商数据手册及外部工具需联网。学习进度仅保存在当前浏览器；阻止本地存储不会妨碍正文阅读。

## 验证范围

- 44 个页面的本地文件链接、锚点、目录次序、40 篇课程唯一标识及进度总数检查通过。

这是课程预览快照。示例按所在页面的工程条件使用，图示不代表真实硬件测量；芯片驱动、算法效果、处理时限和整机功能仍需实际硬件验证。无线升级支线属于设计教学，不表示仓库已经实现完整固件升级。
