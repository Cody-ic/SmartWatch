# 2026-10-23 软件修复记录

原始核验聚焦两个固件的实际 C 代码和 Flutter/Android 代码。下列修改已经过构建与主机回归；详细代码修改前备份保存在本地 STM32 工程 `.backup/2026-10-23-verification-fixes`。

| 序号 | 故障 | 修复 |
| --- | --- | --- |
| 1 | 二分类睡眠概率相加得到约 1 | 使用 `probs[1]`，按宏定义数组并编译检查维度 |
| 2 | 偏移 2 处创建 float 视图产生对齐异常 | ByteData 小端解码、长度和数值验证、独立副本 |
| 3 | 128 字节 RX 环只能容纳 127 字节 | 扩至 1024 字节，独立接收字节、溢出重同步和逐片确认 |
| 4 | CH582M UART1 同时发送调试文本 | 禁用 DEBUG，移除启动文本，加入冲突配置编译检查 |
| 5 | 两字节内容可触发不完整恢复提交 | BEGIN、事务、固定尺寸、位图、CRC、浮点校验和最终提交 ACK |
| 6 | SpO2 断流后旧值持续有效 | 无样本也执行过期检查，保留真实测量时间，App 清除无效/过期数据 |
| 7 | 示例联系人进入真实短信流程 | 默认空列表，精确迁移旧示例并保留原始内容，检查空联系人和权限 |
| 8 | 累计睡眠分钟被重复累加 | 使用最新累计监测时长，移除无依据的固定比例 |
| 9 | 100 Hz IMU 被当作 104 Hz，PPG 旧尾部入窗 | 使用原始 26 点批次，实际 PPG 数量，缺失窗口拒绝，一次消费 |
| 10 | 备份按收包次数判断完整，重复可替代缺片 | 匹配事务、唯一索引、逐片长度、超时和 CRC |
| 11 | CH582M FIFO 空间不足发生部分写入 | 整块接受/拒绝，GATT Write 响应，App 串行 MTU 分块，RX 4096 字节 |
| 12 | 短信把收件人姓名当作遇险人 | 正文明确使用手表佩戴者 |

验证：STM32/CH582M 构建通过，Flutter analyze 无问题，18 项 App 测试、11 组生产 C 回归及双向协议 fixture 通过，Debug APK 构建完成。

硬件核验是随后新增的检查，没有修改原始 EDA/网表/Gerber，结论见 [PCB 报告](pcb-review.md)。软件修复通过不代表这些硬件问题已经关闭。
